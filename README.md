# 🚀 AI Startup Idea Validator

A full-stack web application that validates startup ideas using AI-based logic.

## 🧠 Features
- Submit startup ideas
- AI-generated validation report
- Stores data in MySQL database
- Dashboard to view all ideas

## 🛠 Tech Stack
- Java 21
- Spring Boot
- Spring MVC
- JPA & Hibernate
- Thymeleaf
- MySQL
- Bootstrap
